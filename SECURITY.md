# Security Policy

This repository contains the Rohlik.cz Homey app, its dependencies, and its
GitHub Actions workflows.

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/PechJiri/Rohlik.cz-HomeyApp/security/advisories/new)
to report suspected security vulnerabilities to the repository maintainer.
Keep vulnerability details out of public issues and pull requests while the
report is being investigated.

Include the affected app version or commit, the relevant component, steps to
reproduce the issue, and its security impact. Redact passwords, session cookies,
API tokens, personal information, and order details from examples and logs.

If you have exposed a real credential, revoke or rotate it with the relevant
service rather than including the credential in your report.
